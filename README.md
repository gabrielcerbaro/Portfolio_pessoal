## 👤 Sobre o Projeto

Este é meu site pessoal, construído do zero sem templates ou frameworks, como parte da minha transição para a área de desenvolvimento web. O projeto está em constante evolução conforme avanço nos estudos — cada atualização reflete um novo conceito aprendido e aplicado na prática.

> *"Consistência é o que constrói evolução real."*

---

## ✨ Funcionalidades

- 💡 Animação de digitação no header com JavaScript puro
- 🃏 Cards com efeito flip 3D em CSS na seção de progresso
- 🖼️ Zoom suave na foto ao passar o mouse
- 📱 Layout responsivo para mobile e desktop
- 🔗 Navegação com scroll suave entre seções
- 📂 Seção de projetos com cards linkados ao GitHub
